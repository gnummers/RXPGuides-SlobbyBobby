# RXPGuides_SlobbyBobby

Alliance-only RestedXP guide addon for the Warlock Dreadsteed quest chain.

## Install For WoW TBC Anniversary

1. Download or clone this repository.
2. Unzip the `RXPGuides_SlobbyBobby` folder into your WoW AddOns directory.
3. On Windows, the folder should end up here:

   `World of Warcraft\_anniversary_\Interface\AddOns\RXPGuides_SlobbyBobby`

4. Make sure the addon folder contains `RXPGuides_SlobbyBobby.toc` and `RXPGuides_SlobbyBobby.lua`.
5. Start WoW and enable `RXPGuides_SlobbyBobby` on the addon selection screen.

## Notes

- This addon depends on `RXPGuides`.
- The guide is Alliance-only.
